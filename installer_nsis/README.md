# How to Create NSIS installer
==================================================

* Install CodeQuery from https://sourceforge.net/projects/codequery
* Copy installed files to other local directory
* Copy the new generated codequery.exe cqmakedb.exe, cqsearch.exe into this directory
* Install Inno Setup
* Set the correct path(s) in CodeQuerySetupTgrGithub.iss
* Generate the installer with inno setup tool
